# Contributing

Thanks for helping! The most useful things you can send:

- **Bug reports** with a sample mesh (a small `.stl` or `.blend`), your Blender version and OS.
  Use the "Bug report" issue template.
- **Meshes where the result looks wrong**: a screenshot of stock Alt+J next to this add-on helps a lot.
- **Ideas** for settings or workflows.

## Code contributions

Please **open an issue before writing code**, so we can agree on the approach first.

The add-on's code is © Pavlo Botsula and released under GPL-3.0-or-later. To keep the project
maintainable long term, code contributions (beyond small fixes like typos or one-line bug fixes)
can only be merged if you agree that the maintainer may also use your contribution under other
licenses. You keep the copyright in your work; you just grant that extra permission. You'll be
asked to confirm this in the pull request.
